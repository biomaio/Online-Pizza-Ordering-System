# Online Pizza Ordering System

## Project Overview
The Online Pizza Ordering System is a web-based application that allows customers to browse the pizza menu, customize their pizzas, manage their shopping carts, and place orders for restaurant pickup.

## Current Progress
The project is currently in the requirements analysis stage.

## Documentation
The `docs` folder contains the initial system requirements report in PDF and ODT formats.

## Future Development
This repository will be updated throughout the project. Future updates may include:
- System analysis and design diagrams.
- Database design and implementation.
- Application source code.
- Testing documentation and results.
